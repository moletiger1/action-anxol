# DESIGN.md — 集団訴訟.jp（仮）

このファイルは現行の視覚設計の正典。`smart contract.pen` の variables と
`docs/pencil-ui-prompt.md` の配色指定（ティール #087F8C × 濃紺 #172B4D）は
**この文書で置き換えた**。実装は `src/app/globals.css` の `@theme` を正とする。

---

## 1. 世界観：罫線と藍

日本の台帳・公文書の組み方を土台にする。装飾ではなく、**情報の格**で階層を作る。

- **影を使わない。** 区切りは罫線の太さで表す（墨 2px / 淡 1px）。
- **カードを積まない。** 既定は面を持たない。面を持つのは、操作を求めるとき
  （`StageBanner`）と状態を示すとき（`StatePanel`、`Dialog`）だけ。
- **明朝とゴシックで役割を分ける。** 見出し・金額・社名は明朝（Shippori Mincho）、
  UI本文・ラベル・注記はゴシック（Zen Kaku Gothic New）。
- **丸めない。** 角丸は 2–5px。丸ピルは使わない。状態は角版の「印」として置く。

### 罫線の使い分け

| 用途 | 指定 |
|---|---|
| 節の始まり（見出しの上） | `border-t-2 border-text` または `.rule-head` |
| 画面見出し（`PageHeader`） | `border-b-2 border-text` |
| 行・項目の区切り | `border-b border-border` |
| 強調する合計行 | `border-t-2 border-text` |
| 抜き出し・注意 | `border-l-2` ＋ 淡い地（`Callout`） |

## 2. 色

色は装飾ではなく意味を運ぶ。藍は現在地と主要操作、朱は確認待ち、赤は重大、緑は完了。

| トークン | 値 | 用途 |
|---|---|---|
| `--color-bg` | `#f2f4f7` | 紙の地 |
| `--color-surface` | `#ffffff` | 面（操作・状態のみ） |
| `--color-text` | `#15181c` | 墨。本文 |
| `--color-text-sub` | `#3d4550` | 補足 |
| `--color-text-muted` | `#666f7b` | 注記（地の上でも 4.5:1） |
| `--color-border` | `#d9dee4` | 淡い罫線 |
| `--color-border-strong` | `#b9c1cb` | 入力欄の枠 |
| `--color-primary` | `#1b3a6b` | 藍。主要操作・現在地 |
| `--color-primary-soft` | `#e8eef7` | 藍の淡地 |
| `--color-amber` | `#9c3a19` | 朱。確認待ち |
| `--color-red` | `#a32217` | 赤。エラー・重大 |
| `--color-green` | `#1f5c3d` | 緑。完了 |

確認済みのコントラスト（すべて 4.5:1 以上）:
本文/地 16.2、本文/面 17.8、補足/面 9.7、注記/面 4.7、注記/地 4.6、
藍/面 11.3、白/藍 11.3、朱/朱地 6.0、赤/赤地 6.4、緑/緑地 6.8。

**色だけで状態を区別しない。** 必ずアイコンと文言を併用する（`Badge` の必須 props）。

## 3. 書体と行長

- 本文 16px / 行間 1.7。補足 13–14px、注記 12–13px。
- 見出しの段差：画面見出し 26–30px、節見出し 18px、小見出し 15–16px。
- **本文の行長は `.measure`（42em ≒ 日本語 42 字）。** `ch` は日本語1字の
  約半分の幅になるため使わない。見出しは `.measure-head`（26em）。
- 金額・人数・日付は `.tabular` で桁を揃える。
- 字間を詰める（`tracking-*`）のは英字のみ。`-0.04em` より詰めない。
- 詰め組みは `font-feature-settings: "palt" 1` を既定で有効。

## 4. Liquid Glass（機能層のみ）

Apple のガイドに従い、**機能層にだけ**使う。内容層には決して敷かない。

- 使う場所：ナビゲーションバー（`.glass`）、下部タブバー・CTAバー（`.glass-bar`）、
  シート・ポップオーバー（`.glass-sheet`）。
- 使わない場所：カード、本文、背景、一覧の行。
- 基準面は白。不透明度 0.72–0.86 ＋ `backdrop-filter: blur() saturate()`、
  1px のハイライト境界。**ガラス自体に色を塗らない。**
- `prefers-reduced-transparency: reduce` と `prefers-contrast: more` では
  不透明な面に落とす（`globals.css` で実装済み）。

## 5. モーション

加減速のある曲線 `--ease-out: cubic-bezier(0.32, 0.72, 0, 1)` を既定にし、
`linear` は使わない。動かすのは `transform` と `opacity` に限る。

| 種類 | 長さ |
|---|---|
| フィードバック（hover・押下） | 80–200ms |
| 面・状態の遷移 | 200–400ms |
| 入場（`.enter`） | 最大 500ms |

- 頻繁に起きる操作に長い動きを足さない。装飾だけの動きを入れない。
- 入場のアニメーションは1画面に1回まで。全節に同じ入場を付けない。
- `prefers-reduced-motion: reduce` では移動と時間を落とす（実装済み）。

## 6. スケルトン

- **実在する非同期境界にだけ**置く。この実装で非同期なのは
  `useClientSnapshot`（localStorage 読み取り）の SSR／ハイドレーション間のみ。
  静的 prerender のルートは即座に描画されるため骨組みを出さない。
- 最終レイアウトと同じ構造・寸法・余白で作り、差し替え時に位置を飛ばさない。
- 200ms 未満で終わるなら出さない（`useDelayedFlag`）。点滅を避ける。
- シマーは周期 2 秒・低コントラスト。reduced motion では静止。
- `SkeletonRegion` で `role="status"` と `aria-busy` を与える。

## 7. 文言

- **見出しはその画面が何であるかを最短で言い切る。** 体言止めの対句・詩的な
  見出し・抽象スローガンを書かない。（旧「同じ問題を、ひとりで抱えない。」は
  「出来事から、共同相談を探す」に変更した。）
- ボタンとリンクのラベルは動詞で始める。同じ操作は最後まで同じ語を使う。
- 説明はレイアウトに任せる。1文で足りるならそれ以上書かない。主語に「私たち」を使わない。
- 数字の羅列で凄さを演出しない。感嘆符と絵文字で装飾しない。
- 未確定の事実（決定方法・本人確認・資産・換算）は「未設定」「未確定」と明示する。

## 8. アクセシビリティ

- 操作領域は 44px 以上（`min-h-11` 以上）。
- フォーカスリングは `:focus-visible` で藍の 2px（`globals.css`）。
- 色以外の手段を必ず併用する（アイコン・文言・罫線の太さ）。
- 表・数値は `.tabular`。反復する単位は列見出しに出す。

## 9. 既知の制約

- `loading.tsx` は置かない。全ルートが静的（prerender）のため、フォールバックが
  初期 HTML に入り初回表示に読み込み UI が挟まる回帰になる（TEST-04 の所見）。
  動的セグメントが生まれた時点で、そのセグメント配下に追加する。
- 影を使わないため、ポップオーバーの浮きは `Dialog` の `backdrop` と罫線で表す。
