# Pencilへの依頼プロンプト

日本語Webアプリ「集団訴訟.jp（仮）」の高精細UIを、Pencil上の編集可能な画面としてデザインしてください。この依頼文だけで内容が理解できるよう、以下に必要な仕様をまとめています。コード実装・デプロイ・実際の送金は不要です。

## 1. サービスと体験の軸

同じ問題を抱える当事者が集まり、資料と共同相談費を用意し、その後に弁護士から提案を募り、参加者による審議で共同相談先を決めるサービスです。相談結果を見て、希望する人が個別に弁護士へ依頼します。案件の作成者が法律に詳しいことを前提にしません。

中心となる価値は「仲間が見つかる」「次にすることが分かる」「お金の使い道と決め方が見える」です。管理者にも、コントラクトで固定された出金条件を迂回できない設計を目指しています。その範囲と、人が確認する事項を必要な場所で説明してください。

情報構造は「事件 → その事件についての募集 → 参加・審議・資金管理」。同じ事件の共通ページは一つ、その中に個人会員向け・法人会員向けなどの募集を置けます。最初の作成者は事件ページを独占できません。UIでは分かりやすい「出来事」「募集中の相談」という表現も使えます。

利用者は、案件を探す人、案件作成者、当事者として参加する人、応援支援者、提案する弁護士です。審議・支出確認などの役割は権限のある人にだけ表示します。管理者が案件を自由承認したり、共同資金を出金したりする管理画面は作りません。

主な導線：案件を探す → 共通事件ページ → 募集詳細 → 当事者登録 → 必要に応じ資料共有 → 相談費の拠出 → 弁護士の提案比較・審議 → 相談結果 → 本人が正式依頼 → 進捗・収支確認 → 返金・回収金の精算。拠出しなくても参加希望を登録できます。

## 2. ビジュアルと共通ルール

落ち着き、透明性、参加しやすさが伝わるデザインにしてください。背景は温かみのある白 #F7F8FA、本文は濃紺 #172B4D、主要操作は深いティール #087F8C、境界線は #E2E8F0。アンバーは確認待ち、赤は入力エラーや重要な問題に限定。派手なグラデーション、硬貨・鎖の装飾、裁判官の木槌、勝訴を煽る写真は使わないでください。

日本語はNoto Sans JPまたは利用可能な読みやすい同等書体。本文16px、補足14px、行間1.6程度。余白は8px基準、角丸10〜12px、影は控えめ。本文の可読幅を保ち、数字・表の桁を揃えてください。色だけで状態を区別せず、ラベルとアイコンを併用。操作領域は44px以上、フォーカス・選択・無効状態も用意してください。

一画面で目立つ主要CTAは一つ。上部に「現在の段階」「次にすること」を置き、詳細はタブや開閉パネルで整理。長いフォームは一段階一目的で、自動保存・戻る・途中再開を表示。公開案件はアカウント登録やウォレット接続なしで閲覧できます。

基本ナビゲーションは「案件を探す」「参加中の案件」「お金の記録」「通知」と「案件を作る」。公開ページにはヘッダー、ログイン後の作業画面には共通サイドバーを使用。モバイルでは下部ナビゲーションと主要CTAを使い、本文に重ねないでください。弁護士用ワークスペースへの入口を分けます。

資金の説明は「この募集の支払条件」「誰が確認するか」「返金できる条件」を優先してください。「スマートコントラクト」「取引履歴」「検証用情報」は詳細へ置きます。支出条件が変更できない範囲と、弁護士業務・銀行送金など人が担う範囲を混同しないでください。

## 3. 作成する12画面

以下を5グループに配置してください。各画面にフレーム名と画面外の短い注釈を付けます。表示する日本語は実際のサービスで使える文言にしてください。

### A：案件を探す・理解する

**A01 案件一覧**

見出し「同じ問題を、ひとりで抱えない。」。企業・サービス・出来事の検索、カテゴリと募集段階のフィルター、案件一覧を配置。事件単位のカードにタイトル、簡潔な概要、募集の数、更新日を表示。最初から訴訟中に見せないよう「参加希望を受付中」「相談費を募集中」などを使います。タイムズ案件を主役にし、補助カードは明示的な架空案件を2件だけ用意してください。巨大な広告用ヒーローより検索と案件を優先します。

**A02 共通事件ページ**

タイトル「タイムズカーの個人情報漏えいに関する共同相談」。出来事の概要、公表資料、分かっていること／未確認のこと、更新履歴を配置。「この出来事について募集中の相談」に個人会員向け・法人会員向けの募集を別カードで表示し、対象と目的から選べる構成にします。「別の相談目的で募集する」は副次操作。複数募集の人数や資金を単純合算しないでください。原本メールや参加者名は公開しません。

**A03 募集詳細**

「法人会員・利用者の共同相談」の例。参加対象、相談したいこと、段階表示、登録・確認人数、目標額と現在額、期限を表示。デスクトップは本文＋右側の参加サマリー、モバイルは縦積み。主要CTA「当事者として参加する」、副次導線「応援として支援する」。タブは「概要」「資料・更新」「弁護士の提案」「お金の記録」。費用欄の近くに「今回集めるのは共同相談費です。訴訟への正式依頼は相談後に本人が決めます」を表示。入金前に使途・決定方法・返金条件を確認できる導線を付けます。

### B：案件作成・参加

**B01 案件作成ウィザード**

段階は「出来事」「似た案件の確認」「募集内容」「公開内容の確認」。企業・サービス名、時期、起きたこと、自分との関係、対象者、公開できる根拠、相談目的を質問形式で入力。違反条文・勝率の入力は不要です。類似候補には「この案件に参加する」「この事件に別の募集を追加する」「別の事件として説明する」を用意。同一事件と確定した重複だけは「同じ出来事はすでに登録されています」として既存ページへ案内。類似判定だけで作成を永久拒否しません。公開内容の確認では公開情報と非公開資料を明確に分け、CTAは「参加希望の募集を公開する」。公開前の一律の第三者承認は不要、資金募集の条件が未設定なら公開後も集金は開始できない状態にします。

**B02 当事者登録・資料共有**

対象条件の確認、自分の利用区分、本人確認の状態、通知メール等の非公開アップロード、内容確認の流れ。収集情報は目的を添え、必要最小限にしてください。参加希望だけの登録と、本人・関係性の確認完了を区別します。ファイルごとに「現在の閲覧者」「弁護士への共有許可」を表示し、全応募弁護士への自動開示はしません。メール・パスキー等のサインインUIを用意し、閲覧段階でウォレット接続を要求しないでください。「登録だけで訴訟を依頼したことにはなりません」と短く説明します。

### C：拠出・弁護士の提案・審議

**C01 共同相談費の拠出確認**

拠出額、支払資産と数量、円換算の参考額、手数料、総額、残高、使途、募集期限、返金条件を表示。今回のルールの確認と資金移動の承認を区別し、事前チェック済みの同意欄は使いません。CTAは金額付き「10 USDCを拠出する」など。確認待ち・処理中・完了・取消・残高不足の状態も用意。「円換算」は参考額で、銀行の円預金をそのままコントラクトが保管しているようには見せません。画面はデモで、資産・チェーンの正式採用を意味しないことを注釈に記してください。

**C02 弁護士提案の比較・審議**

架空の弁護士A・B・Cの提案を比較。今回の相談費用、相談範囲、調査内容、納期、担当体制、実費、将来の訴訟費用の提示状況を同じ項目で表示します。相談先の選定と訴訟の委任を混ぜません。AI勝率や自動順位は不要です。専門家の説明、参加者の質問、回答、審議記録への導線を設けてください。権限のある審議役だけに採択操作を表示し、一般参加者は質問・意見投稿ができます。「誰が選ぶか」のパネルに母集団、選任方法、利益相反確認、決定条件を表示。未確定の人数・定足数を勝手に5人中3人等で埋めないでください。未設定・条件未達では決定できない状態も作ります。

**C03 弁護士向け提案作成**

弁護士用ワークスペース。対象者の概要、登録・確認人数、資料の種類、相談目的、予算を匿名の集計で表示。資格・本人確認の状態を置き、相談範囲、税込報酬、実費の上限、支払条件、納期、必要資料を入力。下書き保存・プレビュー・提案送信を用意。利益相反確認の前に原本を閲覧できるUIにはしません。実在しない登録番号・実績・認証済みバッジを作らないでください。

### D：参加後の進捗とお金

**D01 参加中の案件・次の行動**

上部に「あなたの次の一歩」。資料の追加、説明への質問、審議への協力、相談結果の確認など、現在必要な行動を一つ目立たせます。参加状態、拠出額、未読更新、進行段階を表示。相談後の状態では、依頼内容・費用・控除条件を確認して「この条件で弁護士に依頼する」導線を用意し、見送る選択も表示。審議による採択だけで正式委任・和解が完了した表示にはしません。

**D02 共同資金の予算・支出**

会計表を主役にし、入金合計、支払済み、未払いの契約済み費用、未拘束残高を区別。「共同相談費」と「訴訟費用」は別の会計として切替。支出行には用途、受取先、上限、金額、支払条件、承認・履行確認の状態、履歴へのリンクを表示。詳細で「契約条件 → 請求 → 確認 → 支払い」の根拠を確認できます。支出確認の操作は該当する担当だけに表示し、任意の宛先への自由送金ボタンは作りません。「この募集の支払条件は、管理者だけでは変更できません」を、対象範囲への説明とともに表示。条件未達、異議確認中、期限付き停止の状態も必要です。

**D03 本人の返金・回収金の精算**

本人だけが閲覧する画面。「相談費などの返金」と「賠償金・和解金の受取り」を分けます。返金側には拠出額、確定費用、返金可能額、手数料、請求状態、CTA「返金を請求する」。所定の条件なら管理者の個別承認を待たず請求できることを説明。別経路から手続きを確認できる詳細導線も置きます。

回収金側には本人分の実回収額、契約済み報酬、未精算実費、既払額、今回の振込額、最終的な収支を表示。「判決・和解が成立」「入金待ち」「一部入金」「精算中」「送金済み」を区別し、勝訴だけで受取済みにしません。銀行口座はマスクし、確認・異議申立ての導線を用意。支援者への成功配当は表示しません。円での回収・銀行送金の担当は明示し、ブロックチェーンが銀行口座も直接制御する表現は避けてください。

### E：共通部品・状態・モバイル

独立したコンポーネントシートを用意。ボタン、入力、検索、タブ、段階表示、状態バッジ、公開範囲ラベル、費用明細、予算進捗、確認ダイアログを再利用可能にします。読み込み中・空状態・入力エラー・権限なし・処理失敗には、理由と次に取れる行動を添えてください。処理中に同じ送金を繰り返させない表示にします。

デスクトップ12画面は幅1440px、主要内容幅1120〜1200px程度。モバイルは幅390pxでA03募集詳細、B01作成・類似案件確認、C01拠出確認、D03本人精算の4画面を追加してください。比較表は項目ごとに並べ替え、横スクロール頼みにしないでください。

フレーム名は「A01_案件一覧_Desktop」の形式。ダイアログや段階違いは親画面の近くに配置。プロトタイプ接続が可能なら主要CTAを接続し、できない場合は画面外に遷移先を注記してください。装飾画像で文字やフォームを一枚絵にせず、編集可能なテキスト・レイアウト・部品で作成します。

## 4. デモデータと表現の制約

全画面に控えめな「デモ」表示を付け、タイムズ案件の人数・資金・進捗が実績だと誤認されないようにしてください。公開資料の参照先として https://share.timescar.jp/news/2026/0928/1815.html を使えます。個人ごとの漏えい項目・被害額・賠償見込みは未確定です。通知メールの個人情報や実在の参加者情報は使用しません。

募集段階の仮データ：登録248人、本人・関係性の確認176人、資料確認124人、拠出112人。これらを一つの「確認済み被害者数」にまとめないでください。共同相談費は目標2,000 USDC、現在1,120 USDC、達成率56%。説明用の仮レート1 USDC＝150円で、目標約300,000円・現在約168,000円と併記。資産・換算レートともUI説明用で、採用決定・現在相場ではありません。

相談予算の仮内訳：法律相談1,200 USDC、初期調査500 USDC、資料整理200 USDC、決済等の予備費100 USDC。C01の拠出例はコントラクトへ送る10 USDC。ネットワーク手数料は別途必要ですが、デモでは見積もりません。実際の資産数量と参考円換算を区別し、同じ状態の画面間で数値を揃えてください。

後日の会計画面は別時点のデモと画面外に注記。D02は入金2,000 USDC、支払済み1,200 USDC、未払いの契約済み費用500 USDC、未拘束残高300 USDC。未拘束残高全額が直ちに返金可能とは限りません。D03の円での精算は架空案件の別シナリオとし、実回収5,000円－税込報酬1,000円－未精算実費100円＝今回振込3,900円。既払い相談費600円、その他費用・返金なしなら最終収支＋3,300円。タイムズ案件の勝訴・回収実績として表示しないでください。

「誰でも賠償金を受け取れる」「登録すれば原告になる」「必ず勝てる」「完全に安全」「無条件の全額返金」「AIが違法と認定」「世界初」といった表示は使いません。類似案件の統合で資金や個人情報を自動移転せず、支援額で議決権や賠償金の取り分が増える表現も避けます。決定方法・本人確認・資産等の未確定事項は画面外の設計注釈へ明記し、未設定なら集金できない状態を用意してください。

## 5. 仕上げ方

まずA03募集詳細・B01案件作成・D02資金管理で共通スタイルを整え、その後に残りの画面とモバイルを作ってください。この依頼の範囲内では、各画面ごとに確認を待たず全画面を完成させてください。

完成時には、12のデスクトップ画面、4つのモバイル画面、共通コンポーネント、主要な状態・遷移が揃っていることを確認してください。特に「自分が参加できるか」「今何をするか」「誰が支出を決めるか」「いくら払い、いくら受け取るか」が、各該当画面で読めることを重視してください。
