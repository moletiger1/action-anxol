版0.1／2026-10-20 UTC。**骨格のみユーザー承認済み。保留の値は本番defaultにしない。** [仕様v0.4](../superpowers/specs/2026-10-09-action-requirements-design.md)の初期案と[段階計画](../superpowers/plans/2026-10-14-backend-implementation-plan.md)のP0要件に対応する採否一覧。承認記録は[判定台帳§10](2026-10-14-p0-decision-register.md#10-2026-10-20のユーザー承認骨格と方針)。

## 0. この文書の位置づけ

- 能力・契約の判定（台帳§2〜§4）とは別に、**ルール初期値の採否だけ**を記録する。
- 承認済み＝本番default候補になりうる値。**保留＝本番defaultにせず、P1実装時に個別承認**（「実装中に自動的に決まる」扱いをしない。段階計画L126、仕様v0.4 L467）。
- ここに書いたことは能力Go・候補採用・G解除ではない。**全27問未回答/E0、G-01〜05未解除は不変**。
- 数値は仕様v0.4の候補値であり、根拠行を併記する。

## 1. 承認済み（2026-10-20、ユーザー）

### 1.1 期限一式（D＝集金を許した募集条件の公開確定時刻）

| 区間 | 値 | 根拠 |
|---|---|---|
| 募集案内 | D〜D+21日 | v0.4 L259 |
| 支払い開始・着金・資格・候補条件確定 | いずれもD+7日締切。D+7日後の着金は資格なしで外部返金処理、公開募集画面は受付終了表示 | v0.4 L259 |
| 初回・決選 | 初回D+7日〜D+14日。必要なら決選D+14日〜D+17日。結果暫定集計まで24時間、D+18日以内 | v0.4 L260 |
| 結果異議・選任 | 暫定集計公開から48時間。最終選任D+21日まで。未解決は選任しない | v0.4 L261 |
| 契約・相談 | 契約条件/予算承認は選任後7日以内、相談実施はD+60日まで | v0.4 L262 |
| 精算・最終終了 | D+90日までに債務確定/保留・準備金・不足と第1返金バッチを公表。新選挙/新支出はD+90日で終了。外部取消リスク終了後7日以内に追加精算。未払債務/返金権利の法的存続は消さない | v0.4 L263 |

### 1.2 投票日程・定足数・採択

| 項目 | 値 | 根拠 |
|---|---|---|
| 投票日程 | 初回7日。定足数ありで過半数なしなら上位2選択肢で決選3日 | v0.4 L251 |
| 定足数 | `Q(N)=max(3, ceil(N/2))`、`T>=Q(N)`、N<3は開始不可（N=3/5/6→Q=3） | v0.4 L249 |
| 採択 | 段階ごとの過半数 `floor(T/2)+1`。棄権・未回答はTに算入しない。見送り過半数で`DECLINED`、候補0人は開始不可、候補1人＋見送りは開始可 | v0.4 L249 |

### 1.4 配分（返金バッチ）

| 項目 | 値 | 根拠 |
|---|---|---|
| 方式 | **上限付き最大剰余**：理想額`f*w/W`が`cap`超の者全員へcap→同時除外し`f/W`更新→超過者0まで反復（整数の交差積比較）→残対象に`floor(f*w/W)`→余りを`cap`未満へ1円ずつ | v0.4 L325, L327 |
| 重み・上限 | `w`＝未取消の拠出額、`W=Σw`、`cap=max(0, 有効拠出-確定した非返還費用負担-完了返金-未完了の固定返金予約)`、`F`はcashからの返金可能額かつ`Σcap`以下 | v0.4 L325 |
| 禁止 | 累計で最大剰余を再計算しない（追加原資は新バッチ）。`cap=0`へ端数集中させない。`W=0`/`F<0`/原資不足/照合不明はバッチ不可 | v0.4 L325, L329 |

## 2. 保留（本番defaultにしない。P1実装時に個別承認）

- **保存期間**：未確認通知・確認トークン24時間、確認済み宛先・購読（同意期間中・削除要求後72時間以内）、メール運用記録7日、通知バックアップ最大30日、独立した停止・削除履歴（全コピー消滅の証拠まで）、セッション8時間、チャレンジ5分/単回、アクセス・エラー記録7日以内（v0.4 L109-123）。**外部事業者と法務の確認が前提**（v0.4 L125）。
- **再試行回数**：返金FAILEDは同一固定指示/同一実行版/同一payloadで24時間以内最大3回（v0.4 L359）、通知再送24時間・最大3回（v0.4 L153）、長期未解決7日で外部請求案内・未請求30日（v0.4 L359）。
- **審査周辺の細目**：暫定承認から12日の最終化/期限切れ（v0.4 L200, L207）、異議窓口7日（v0.4 L201）、再審査の受理判定48時間/再審査72時間（v0.4 L213）、再照合・再署名48時間/12日（v0.4 L221）、検収72時間・異議48時間・裁定72時間・許可最終化後72時間内の銀行実行（v0.4 L296-299）。
- **統治パラメータ**：立上げ評議会5人・3/5・任期90日（v0.4 L410）、提案公開7日+3日投票（v0.4 L414）、G解除/再停止の解除前7日公開（v0.4 L416）、緊急停止72時間（v0.4 L419）、表示保留の最大24時間（v0.4 L418）。
- **主体付き閾値の未承認分**：検収3/5、異議裁定3/5、返金バッチ署名3/5、立上げ評議会3/5（v0.4 L291, L297, L325, L410）。
- **レビュアー母集団（初期案）**：15人以上・任期90日、利害除外後10人優先、初回待機上限14日、事前確保5人（v0.4 L209, L211）。
- **参加条件（初期案）**：本人の1円以上の確定拠出を要し代理払い不可（v0.4 L173）。
- **技術方式（未選定）**：合意基盤、採用hash/署名アルゴリズム、ドメイン分離、時刻許容差、基盤最終性、issuer/policy、私的会計の権威ある保管、リレー費用（v0.4 L5, L383、段階計画L39）。
- **費用・責任主体・法的主体**：費用の具体額・負担率（v0.4 L285, L321）、責任主体の実名（質問票L21）、法的主体・請求経路・残余リスク（P0-06）。
- **配分の端数同順位**：仕様は「同順位用のランダム参照辞書順」（L325）と「端数降順/固定参照順」（L327）の2表現があり、**統一が必要**。

## 4. fixtureと本番defaultの分離

- 承認済み（§1）のみ本番default候補。保留（§2）はfixtureでのみ使用し、本番defaultへコピーしない。
- 実装中に自動決定しない。値を変える場合は版・承認日・対象版を台帳へ記録する。
- manifestの実ファイル名・スキーマは**未定**（段階計画L36は「草案を作る」とのみ）。
