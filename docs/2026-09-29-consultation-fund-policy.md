# 集団訴訟.jp（仮）：相談前の仲間・資金募集を中心にした改訂方針

**現行方針は [参加者が審議し、資金を共同管理するサービス方針](2026-09-29-community-governance-policy.md)。** 「固定の運営会社なし・参加者による審議あり」への合意により、以下の作成者による単独選定・運営による審査を更新した。以下は検討履歴として残す。

2026年9月29日。ユーザーの「人が集まって、費用がたまってから弁護士に相談したい」という意図を基準にした現行方針。前の事業方針のうち、弁護士向け管理ソフトを中心とする優先順位と、資金募集を初期版から外す方針を改める。未実装・未公開・未集金。

## 設計原則の追加：法律知識を作成・運営の参加条件にしない

ユーザーの追加要望により、作成者が請求根拠や弁護士の専門能力を審査し、運営が毎案件の法的成立性を判断する設計にはしない。作成者は自分が経験した事実・手元の資料・希望する対応を登録し、運営は事前に定めた掲載条件・本人確認・資金管理ルールへの適合を確認する。請求根拠・対象者の法的な範囲・受任可否・訴訟方針は、集まった案件を検討する弁護士が判断する。

### 作成者の入力例：タイムズ第一号

「法律違反の条文」「勝訴見込み」「適切な慰謝料」は尋ねない。「タイムズカーに登録しているか」「通知を受信したか」「通知に何と書かれているか」「実際の支出があるか」「弁護士に何を相談したいか」を尋ねる。本文から抽出・要約した内容には元の箇所を対応させ、本人が確認する。不明は不明のまま登録する。

例示する募集文は「タイムズカーの情報漏えい通知を受けた方などから、状況と参加意向を集め、共同での請求が可能か弁護士に相談するための費用を募集します」。参加できる人の法的な範囲や請求の成否が確定した表現にはしない。

### 自動化の限界と例外処理

必須項目が埋まっていることや出典URLがあることは、内容が真実・適法である保証ではない。AIは抽出・下書き・確認箇所の提示までに限定し、法的成立性の自動採点、勝率推定、個別案件の弁護士の優劣評価をしない。

第一号の標準経路は、企業の公式発表がある情報漏えい案件に合わせる。別種の事件も下書きは可能にし、標準様式で扱えないものは手動確認へ回す。権利侵害の疑い、対立する資料、未成年者・医療情報等の扱い、通報・異議などは公開保留や限定共有にし、必要に応じ外部の法務担当へ照会する。運営スタッフが法的な結論を即断する必要はない。

サービス全体の掲載ルール、資金・返金・提供先同意、弁護士との直接連絡と料金の関係は、公開前に専門家と設計し、制度・運用変更時に見直す。共通ルールと例外対応を専門家に依頼することと、案件ごとに募集前の弁護士受任を必須にすることを区別する。前者は必要な運営体制、後者は採用しない。

日弁連の指針は、直接連絡フォームの提供のみの場合と、運営による弁護士の選別・受任勧奨等を区別している。したがって、自動化すれば何をしてもよいとは扱わず、提供機能・宣伝・課金の実態を合わせて確認する。[指針](https://www.toben.or.jp/know/iinkai/hibenteikei/pdf/kaiki_no_70_02.pdf)

## 1. 中核となる体験

**案件を作る → 当事者・情報・予算を集める → 弁護士から相談・受任条件の提案を募る → 当事者側が候補を選び相談する → 各人の委任と弁護士の審査を経て交渉・提訴へ進む。**

追加要件：ユーザーは、人数と情報がまとまった案件に弁護士が「入札」できる仕組みを希望している。最安値で自動落札・自動受任とするのではなく、費用・対応方針・条件を同じ形式で比較できる提案募集として具体化する。弁護士の決定は募集の後に行う。

弁護士決定・受任を案件募集の開始条件にしない。初回の資金使途は、弁護士への相談・初期調査・合意された資料準備と、それに必要な明示済みの費用とする。訴訟費用の見積もりが出る前に、裁判全体の費用が確保できたと表示しない。

サービスの約束は「一人で相談費用と準備を背負わず、仲間と予算をそろえて相談に進めること」。相談の結果、請求や訴訟を見送ることもある。その場合でも適正に行われた相談の費用は発生することを、支払い前に示す。

## 2. CALL4との差と、まだ検証が必要なこと

CALL4の掲載条件は、相手方が国・自治体、代理人弁護士がいること、提訴済みまたは間近であることなど。提訴が不明確な段階で弁護士費用の準備を目的に掲載することはできないと明記されている。したがって「民間企業に関する問題について、弁護士への相談前から仲間と資金を集める」は、公表されたCALL4の対象範囲との具体的な違いになる。

出典：[CALL4・掲載条件](https://www.call4.jp/other.php?key=toLawyers)（2026年9月29日確認）

ただし、一般のクラウドファンディングや被害者団体による資金募集にも代替され得る。新規性や独占的な強みが証明されたわけではない。案件の当事者登録、相談目的の予算・実績、相談結果の報告、正式依頼への個別意思確認を一つにまとめる価値を検証する。

| 作成 | 出来事・対象者・相談したい内容・予算内訳・期限・支出責任者を記入 | 関係する案件を探す | 出典・作成者・募集条件を審査し公開 |
| 募集 | ページを共有し、状況を更新 | 当事者登録、任意の資金拠出。支援のみの参加も可 | 当事者数と支援者数、決済済み額、目標、期限を区別して表示 |
| 成立後 | 人数・証拠概要・予算を示して弁護士の提案を募り、比較して相談候補を選ぶ | 自分の資料の共有先を確認し、必要な共有に同意 | 当事者側の選択を支える提案比較と直接連絡。予算・実支出・未使用残高を記録 |

相談を申し込む人と相談の依頼者を明示する。代表者の相談だけで全参加者の受任が成立することはない。法的助言の共有範囲は相談先と合意し、非公開の報告に他人の個人情報や訴訟戦略を無断掲載しない。

初期版の5機能は、案件作成・審査、募集ページと当事者登録、目標付き資金募集、弁護士の提案・比較、進捗・会計・相談結果の報告。弁護士向け高度な管理画面より優先する。

### 弁護士に見せる案件の概要

当事者が共有範囲を確認した上で、事件の公式出典、参加希望人数、本人申告と資料確認の内訳、対象区分、被害・証拠の種類、希望する解決、利用可能な予算と使途制限を示す。登録者数を原告数や請求権が確認された人数と扱わない。出資・支援した人だけを当事者数として数えない。

最初の閲覧には個人を特定できる資料を含めず、集計の組合せから個人が分かる少人数の内訳も出さない。関心を示した弁護士に必要な詳細を開示するときは、登録資格と本人の確認、提供先への同意、利益相反確認の手順を踏む。全参加者の証拠を全応募弁護士に公開しない。

### 提案の比較項目

| 項目 | 弁護士に記載してもらうこと |
|---|---|
| 費用 | 相談・初期調査の料金、訴訟受任時の着手金・成功報酬・実費、税込区分、最低人数等の前提、未確定項目 |
| 進め方 | 確認したい論点、追加で必要な証拠、交渉・訴訟等の検討方針。事前調査なしに勝訴を保証しない |
| 担当体制 | 担当弁護士、関連分野の経験、対応できる人数、連絡・報告方法 |
| 条件と時期 | 受任審査条件、相談可能時期、調査の見込み期間、条件の有効期限、条件変更時の再同意 |

提案は当事者側に非公開で提出し、競合の弁護士や一般閲覧者には見せない。初期案では作成者が相談候補を比較し、理由を示して選ぶ。参加者は提案を読み、質問・意見を出せる。共通資金による初期相談先の選択と、各人が訴訟を委任する弁護士の選択を区別する。個人ごとに契約・委任を確認し、弁護士が受任を承諾した後に担当状態を確定する。運営が案件ごとに推薦順位を付けたり、作成者の代わりに選定したりしない。

### 誰が弁護士を選ぶか：初期版の意思決定ルール案

以下は採用を提案する運営ルールであり、法令上の標準手続ではない。

1. **募集時に権限を明示する。** 初期相談先の選定を行う代表者を指定し、相談目的・予算上限・選定手順を支払い前に示す。支援者はこの目的と手順を確認して拠出する。目的外支出、訴訟委任、追加負担への包括同意として扱わない。
2. **代表者が候補を比較する。** 応募が複数あれば2〜3候補に絞り、案件の対象者・必要証拠・費用・体制に関する同じ質問をする。応募者一覧、候補を絞った理由、既存の関係や利益相反を参加者に示す。候補が1人だけならその旨を明示し、無理に複数案を作らない。
3. **参加者に説明する。** 費用・進め方・担当体制・受任条件の比較を示し、原則3日間の質問・意見受付期間を置く。意見は参考とし、無回答を個別の委任や追加支出への賛成と扱わない。期限の事情がある場合の扱いも事前に募集条件へ記載する。
4. **代表者が初期相談先を決める。** 当初の使途・上限・手順の範囲内で選び、理由と金額を記録する。変更が必要な場合は新条件への同意または新たな募集を行う。代表者には単独・無制限の出金権限を持たせず、支出実行時には予算・請求書との一致を別担当が確認する。個人的な紹介報酬の受領は禁止する。
5. **正式依頼は本人が決める。** 初期相談後、弁護士が受任条件を示し、希望者が個別に委任する。不参加を選べる。正式依頼を見送っても、すでに合意に基づき支出した共通相談費が当然に返金される扱いにはしない。

候補の専門的な良し悪しは、アプリが保証しない。登録確認は弁護士本人・資格の確認に限定して表示する。案件の争点、追加証拠、対象者を分ける必要性、費用の前提を具体的に説明してもらい、実際に担当する弁護士と面談して判断する。法的見解が大きく食い違い判断できない場合は、事前の予算・使途に含めた第二の法律相談を検討する。

多数決は初期版の決定機能にはしない。支援額に応じた票数や全員一致は採用しない。将来、投票で共通相談先を決める案件を追加する場合は、有権者、本人・重複確認、定足数、同票・不成立時の処理、異議と返金の条件を拠出前に確定する。いずれも個別の訴訟委任を代替しない。

### 案件の作成・承認：公開と集金を別に審査する

| 段階 | 作成者の入力・対応 | 運営の判断と画面 |
|---|---|---|
| 下書き | 自分の立場・本人確認、出来事・対象、求める対応、公式出典または自身の資料、運営連絡先 | 非公開。入力目標10〜15分。証拠原本を公開欄へ貼らせない |
| 掲載審査 | 不足・修正指摘に対応 | 下記基準で「承認／修正依頼／掲載不可」。理由と再申請方法を示す。初期の対応目標は3営業日以内とし、法的審査の完了期限とはしない |
| 公開・参加募集 | 当事者登録と更新通知を募集 | 「掲載基準確認済み／法的判断前」と範囲を表示。弁護士未決定でも公開可。集金は別審査の承認まで無効 |
| 資金募集審査 | 目的・予算内訳・期限・代表者の権限・支払先管理・未達や相談不能時の返金・残金処理を記入 | 実施できる決済・返金の仕組みと説明の整合性を確認し、資金募集を有効化。掲載審査と同時申請も可 |
| 公開後 | 更新、訂正、使途変更・担当変更を申請 | 通報受付、修正、募集一時停止・終了。重要変更は再審査し、必要な再同意を得る。終了や非公開化だけで会計・返金責任を消さない |

掲載審査の基準は次の5項目に固定する。

1. 作成者の本人・連絡先と、当事者または権限ある支援者であることを確認できる。
2. 出来事の説明に確認可能な根拠がある。会社の発表や報道がない案件も、自身の契約書・通知等で検討可能にする。
3. 同じ問題の当事者を募集する範囲・目的が具体的で、参加条件が説明されている。
4. 未確定の主張を断定しておらず、個人情報の暴露、脅迫、嫌がらせを目的とする内容を含まない。
5. 同一事件の既存案件との関係、作成者の利害、役割と更新の責任が明らかである。

事実をすべて立証済みであることや、勝訴・賠償が見込めることを公開の条件にしない。「運営承認」を「被害の法的認定」「弁護士のお墨付き」と表示しない。権利侵害のおそれがある表現や判断困難な資料は公開を保留し、必要な専門確認を行うが、全案件で事前に訴訟代理人の就任を求めない。

初期は招待制で1〜3件を人が審査し、自動承認や群衆投票による公開判定は導入しない。タイムズ第一号のようにプラットフォーム運営者が作成者を兼ねる案件では、本人以外の審査担当を置き、通常案件と同じ基準・記録を使う。独立した担当者を用意できるまでは審査済み表示をしない。

提案には「初期相談のみ」「資料確認後に受任判断」「条件付き受任案」の区分を持たせる。初期予算を訴訟の着手金へ自動充当しない。条件付き提案だけで提訴確約とは表示しない。応募がない、条件が合わない、受任対象が一部に限られる場合も記録し、募集の終了・再設定と未使用資金の処理につなげる。

### 提案募集の運営と法的な確認点

運営は、弁護士の登録確認と掲載規則の管理、定型フォーム、当事者と弁護士が直接やり取りできる機能を担当する。運営が個別相談を評価して担当を割り当てたり、受任を勧めたり、成約・落札に連動した紹介料を受け取るモデルは採用しない。

日弁連の指針は、運営による選別、受任等の勧奨、相談内容を弁護士選定に使う行為などを問題になり得るものとして挙げる。一方、定型フォームを含む直接連絡の仕組みを設けるだけの場合は、直ちに周旋と評価しない旨も示している。したがって、利用者が選ぶ画面にするだけで適法性が確定するわけではなく、宣伝・募集・情報加工・課金を含む実態を確認して公開する。[日弁連の指針](https://www.toben.or.jp/know/iinkai/hibenteikei/pdf/kaiki_no_70_02.pdf)

弁護士の立候補自体はenjinにも先例がある。今回の検証対象は、当事者と予算が集まった案件について、資料の確認状況と費用・方針の提案を比較できる一連の体験である。[enjinのサービス説明](https://enjin-classaction.com/about/user/)

## 4. お金の扱い

1. **募集時に決めること**：相談の目的、概算予算の根拠、目標総額、募集期限、成立条件、相談実施期限、手数料、返金条件。相談先未定・価格未確定を表示する。例示金額を実際の弁護士見積もりと誤認させない。
2. **未達の場合**：期限までに目標額に達しなければ不成立・全額返金を基本設計とする。実際に使う決済・募集基盤がその条件を履行できることを確認してから受付を始める。
3. **達成後の場合**：使途・予算を固定し、相談請求書等に対応する支払いと証憑を記録する。相談先が見つからないまま実施期限を過ぎた場合は未使用分を返す。資金を取り出せる人、承認者、決済実行者を明示する。
4. **相談実施後の場合**：結果が不利でも、適正に支出した相談費用は返金対象にしない。未使用残金は事前に示したルールで按分返金する。決済・返金費用の負担は支払い前に明示し、原則として超過募集は受け付けない。
5. **次段階の場合**：追加調査や訴訟費用は、見積もりと条件を示して別の募集・同意を行う。当初予算を作成者の判断で転用しない。支援額に応じた賠償金の分配・投資リターンは設けない。

目標未達時に返金する方式には一般的なクラウドファンディングの先例がある。[CAMPFIREの不成立時の説明](https://help.camp-fire.jp/hc/ja/-all-or-nothing%E3%81%AE%E3%81%BF-%E3%83%97%E3%83%AD%E3%82%B8%E3%82%A7%E3%82%AF%E3%83%88%E3%81%8C%E6%88%90%E7%AB%8B%E3%81%97%E3%81%AA%E3%81%8B%E3%81%A3%E3%81%9F%E5%A0%B4%E5%90%88%E3%81%AF%E3%81%A9%E3%81%86%E3%81%AA%E3%82%8B%E3%81%AE%E3%81%A7%E3%81%99%E3%81%8B)。これは本案件が同サービスに掲載可能であるとの確認ではない。

第一号では、資金を一旦運営の通常口座に集める仕組みを独自実装せず、使途・審査条件に対応できる外部の募集・決済基盤を選定する。募集額、振込時期、手数料、返金可能性を確認し、上記の設計に合わない場合は受付前に条件を修正する。既存基盤の利用だけで資金管理・法的問題がすべて解消するとは扱わない。

案件の弁護士への相談は人と資金が集まった後に行う。一方、サービス運営者による資金の扱い・手数料・役割に関する制度確認は、実際の集金開始前に必要な公開準備とする。両者を混同して、案件募集前に弁護士の受任を要求しない。

## 5. 収益化・集客の修正

第一号は運営手数料を0円として募集・相談実施までの工数を測る案とする。決済等の実費は予算に含め明示する。将来は募集・会計・連絡機能の利用料を検討するが、具体的な料金と徴収時点は、実態が有料の法律事務の周旋にならないかを確認してから決める。固定料金やクラウドファンディング手数料という名称だけで適法とは判断しない。[日弁連の指針](https://www.toben.or.jp/know/iinkai/hibenteikei/pdf/kaiki_no_70_02.pdf)

集客文句は「同じ問題の仲間と相談費用を集めよう」。第一号のタイムズ案件でも、何を弁護士に相談するのか、必要な予算、資金の扱いを前面に出す。共有カードには人数・金額・期限を表示し、当事者本人の参加状況や個人情報は含めない。

成果指標は募集成立率、実際に相談まで到達した割合、相談までの日数、代表者の作業時間、返金の完了率とする。訴訟に進まないとの判断も、相談を実施し会計・結果を報告できれば一つの完了とする。

次に具体化する画面は、案件ページ上の「当事者数」「決済済み金額と目標」「期限」「予算内訳」「相談後・不成立時の扱い」と、当事者登録・費用支援の二つのボタン。
